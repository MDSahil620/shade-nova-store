# Shade Nova Store 🕶️

**Shade Nova** is a modern, single-vendor e-commerce web application built using Python and Flask. It is designed specifically for showcasing and selling exclusive eyewear, glasses, and accessories with a smooth user experience and an intuitive admin management system.

---

## 🚀 Features Implemented (Completed Work)

* **Catalog & Home Page:** Clean and responsive landing page to display products seamlessly.
* **Product Management:** Dynamic database integration to manage product details, pricing, and stock.
* **Admin Authentication & Dashboard:** Secure login system (`/admin`) for managing store items[cite: 5, 8].
* **Local Development & Routing:** Fully configured Flask backend routing (`app.py` / `main.py`) running locally on `127.0.0.1:5000`[cite: 2, 7].
* **Version Control:** Managed and tracked via Git and pushed to GitHub under the repository name `shade-nova-store`.

---

## 🛠️ Tech Stack

* **Backend:** Python, Flask, SQLAlchemy (Database)
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite / Local Database setup
* **Tools:** Visual Studio Code, Git & GitHub
